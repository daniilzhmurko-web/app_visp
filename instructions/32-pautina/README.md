# Учебный тренажёр ЦАФАП — многофайловый сайт

Сайт работает **без сервера**: достаточно открыть `index.html` двойным щелчком (протокол `file://`) или
положить папку на любой статический хостинг. Интернет не нужен — шрифты иконок и Chart.js лежат в `vendor/`.

> Все данные в базах **синтетические**: персоны, номера, VIN, документы и штрафы вымышлены.
> Снимки фиксации — **не фотографии**, а процедурно нарисованные сцены.

## Структура

```
index.html            ← тренажёр (вход → 6 этапов → отчёт)
databases.html        ← просмотр баз данных (поиск, постраничный вывод, CSV, предпросмотр снимков)
css/main.css          ← стили
js/
  db/db.js            ← слой доступа к базам (CAFAP_DB): поиск по номеру/VIN/ФИО, выборки для сценариев
  core/token.js       ← токен подлинности (ФИО из токена, печати в отчёте)
  core/app.js         ← каркас: вход, навигация, панель заданий, отчёт
  stages/stage1..6.js ← этапы 1–6
data/                 ← БАЗЫ ДАННЫХ (генерируются, не править руками)
  fis_gibdd_m.js      ← ФИС ГИБДД-М: владельцы, водительские удостоверения, ТС, розыск, ограничения
  fixations.js        ← база фиксаций: параметры снимков, результат OCR
  gis_gmp.js          ← ГИС ГМП: начисления и платежи по штрафам
  fssp.js             ← ФССП: исполнительные производства
  photos.js           ← пользовательские фото (по умолчанию пусто; создаёт tools/import-photos.js)
  fvf_complexes.js    ← реестр комплексов фото-видеофиксации (камер)
  nsi.js              ← НСИ: регионы, статьи КоАП, марки/модели, цвета, типы комплексов
assets/
  img/                ← логотип ЦАФАН, favicon
  snapshots/          ← 320 синтетических снимков фиксации (SVG), по одному на запись базы фиксаций
  photos/             ← реальные фото (появляется после tools/import-photos.js)
vendor/               ← Chart.js и Font Awesome (локально)
tools/                ← генератор баз и снимков (Node.js)
```

## Что откуда берётся

| Этап | Использует базы |
|---|---|
| 1 — Дашборд | **fvf_complexes** (камеры); **fis_gibdd_m** (очередь нарушений, окно «Запрос ФИС ГИБДД-М») |
| 2 — OCR | **fixations** (очередь, снимки, OCR-результат), **fvf_complexes** (метаданные комплекса), **fis_gibdd_m** (поиск владельца: розыск, ограничения, ОСАГО, ВУ) |
| 3 — Постановления | **fis_gibdd_m** (владельцы, ТС) |
| 4 — Почта/ФССП | **gis_gmp** (постановления, УИН, суммы, статусы оплаты — почтовая очередь, контроль оплат, ст. 20.25), **fssp** (исполнительные производства, статистика), **fis_gibdd_m** (адресаты), **nsi** (статьи) |
| 5 — Аналитика | **fis_gibdd_m** (реестр розыска), **fvf_complexes** (карта камер, реестр) |
| 6 — Администрирование | **nsi** (справочник статей КоАП) |

Не из баз (генерируются самим этапом): ленты событий и метрики этапа 5 (трафик, KPI операторов), пользователи
и роли этапа 6, часть статистики на дашборде этапа 1. Страница `databases.html` показывает ровно те таблицы, на которые опирается тренажёр.

Сценарные номера из заданий (`А177МС77`, `О917ММ177` и др.) всегда присутствуют в ФИС.
Номера можно вводить латиницей — они нормализуются в кириллицу (`A177MC77` → `А177МС77`).

## Карта камер (этап 5)

Карта построена на **Leaflet** (локально в `vendor/leaflet/`) с наложением: цветные точки — статус камеры,
полупрозрачные круги — «нарушений за сутки» (площадь пропорциональна значению). Легенда и переключатель слоёв — внутри карты,
клик по строке реестра подводит карту к камере. Подложка — плитки OpenStreetMap (нужен интернет, настройка `CAFAP_MAP` в
`js/core/app.js`; для большой нагрузки подставьте своего провайдера — см. политику плиток OSM). Без интернета через несколько секунд
автоматически включается **офлайн-схема** (МКАД, ТТК, Садовое кольцо, Москва-река — условная схема).

## Токен доступа

Как в SOPS-тренажёре: токен вида `base64(JSON).подпись` вставляется на экране входа или передаётся ссылкой
`index.html?token=…`. ФИО берётся из токена и блокируется; в отчёт попадают `token`, `renderSeq`,
`cadet.syncTag`, `uiInstance`. Без токена вход работает по ФИО и номеру взвода. Подпись страница не проверяет —
это делает проверяющий (`universal_checker`).

## Пересборка баз и снимков

```
node tools/build.js            # базы (data/*.js) + снимки (assets/snapshots/*.svg)
node tools/build.js --no-snap  # только базы
```

Генерация детерминирована (seed в `tools/lib/db-builder.js`). Объём и состав настраиваются там же:
число владельцев (`PERSONS`, `ORGS`), ТС (`TOTAL`), начислений, фиксаций (`TOTAL_FIX`).
Параметры сцены снимка (кузов, цвет, свет, погода, состояние номера) заданы в записи фиксации,
рисует их `tools/lib/snapshot-renderer.js`.

## Реальные фотографии вместо синтетических

Тренажёр показывает «фотоматериал» в формате реальных комплексов: 4 кадра (обзорный, следующий через 0,6 с,
фото ТС, увеличенный номер) с зелёными рамками детектора и текстовым блоком (нарушение, комплекс, дата и время
с миллисекундами, адрес, направление, координаты). Синтетические снимки и реальные фото показываются одинаково.

**Порядок работы**

1. Подберите фотографии (источники — ниже) и положите в одну папку. Для каждого фото желательна разметка YOLO
   с тем же именем и расширением `.txt` (`класс xc yc w h` — рамка номера в долях кадра).
2. **Замените настоящие номера вымышленными** (рекомендуется всегда):
   `python tools/replate.py <папка_с_фото> <выходная_папка>` — рисует вымышленный номер по рамке
   и записывает `plates.csv`. Нужен Pillow (`pip install pillow`) и шрифт с кириллицей (`--font arialbd.ttf`).
3. Импортируйте: `node tools/import-photos.js <выходная_папка> --source "URL набора" --license "CC BY 4.0"`.
   Инструмент копирует фото в `assets/photos/`, создаёт вымышленных владельца и ТС в ФИС, запись в базе фиксаций,
   пишет `data/photos.js` и `assets/photos/ATTRIBUTION.txt` (источники и лицензии для соблюдения условий CC BY).
4. Доля реальных фото в очереди этапа 2 задаётся `CAFAP_REAL_SHARE` в начале `js/db/db.js` (по умолчанию 0,5).

Без файла разметки рамки в «фотоматериале» будут приблизительными (фото всё равно покажется).

**Где взять фото (проверяйте лицензию каждого набора перед использованием)**

| Набор | Что внутри | Лицензия по описанию |
|---|---|---|
| Hugging Face: `AY000554/Car_plate_detecting_dataset` | ~25 500 фото автомобилей с российскими номерами + разметка YOLO (рамка номера); основан на AUTO.RIA Numberplate Dataset (Nomeroff Net) | оригинальный набор — CC BY 4.0 |
| Roboflow Universe: `g15/car-license-plates-rus`, `neopoleones/car-license-plates-dataset` и др. | детекция российских номеров | CC BY 4.0 (на странице каждого набора) |
| Roboflow Universe: `license-plates-f8vsn` | подмножество Open Images | изображения CC BY 2.0, разметка CC BY 4.0 |

Это в основном объявления о продаже автомобилей и любительские снимки, а не кадры камер ЦАФАП. CC BY требует
указания авторства — `ATTRIBUTION.txt` заполняется автоматически, если указаны `--source` и `--license`.
Скачиваются эти наборы вручную (инструмент сам ничего не загружает из сети).

**Юридическая оговорка.** Фотографии с читаемыми настоящими номерами и вымышленными владельцами — это
недостоверные сведения о реальных автомобилях и их владельцах. Используйте `replate.py`, фото с согласия владельцев
или собственные снимки. Реальные материалы ГИБДД/ЦАФАП (постановления, фотоматериалы) с чужими данными в учебный
сайт загружать не следует. По вопросам персональных данных проконсультируйтесь с юристом.

## Настройка скидки на штраф

В начале `js/core/app.js`: `const CAFAP_DISCOUNT = {pct:50, days:20};`.
Сейчас стоят значения исходного курса; ряд изданий указывает, что с 01.01.2025 для большинства
нарушений действует 25% при оплате в течение 30 суток (`{pct:25, days:30}`) — сверьте с действующей
редакцией КоАП. Подсказки, расчёты и вопрос теста подстраиваются автоматически.

## Проверка

Сайт проверен в jsdom (загрузка по `file://`): сквозной прогон ~2 900 кликов по всем разделам, сценарии
этапов 1–6, вход с токеном и без, страница баз данных. В реальном браузере рекомендуется один раз пройти
интерфейс глазами.
