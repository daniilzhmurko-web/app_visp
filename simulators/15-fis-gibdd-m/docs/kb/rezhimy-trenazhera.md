# Режимы тренажёра и начисление очков
tags: режим, обучение, экзамен, sandbox, очки, баллы

Обучение — подсказки включены; Экзамен — подсказок нет, инструктор и справочник недоступны, проверяется каждый шаг; Sandbox — свободная работа без случайных событий; Преподаватель — внедрение аномалий.
Очки начисляются один раз за каждый объект (ТС, постановление, платёж и т. п.); для массовых действий есть лимиты. Задание продвигается только действиями в «своём» разделе. 5 ошибок в задании — провал.
