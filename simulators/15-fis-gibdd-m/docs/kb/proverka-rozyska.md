# Проверка ТС по базе розыска
tags: розыск, проверка, угон, регистрация

Перед любым регистрационным действием проверяйте ТС по VIN и госномеру (кнопка «Проверить розыск»). Совпадение с **активной** записью — немедленный отказ и уведомление дежурного.
Запись о розыске снимают только в разделе «Розыск» («Снять»), для этого нужно основание. Снятая запись остаётся в архиве; ТС может быть объявлено в розыск повторно.
Поиск по ГРЗ К777АВ77 в учебной базе даёт ТС в розыске.
