# Формат госномера
tags: номер, грз, формат, регион

Формат: буква, три цифры, две буквы, код региона (2–3 цифры), например А123ВС77.
Допустимые буквы — только совпадающие по начертанию с латинскими: **А В Е К М Н О Р С Т У Х**. Латинские буквы при вводе распознаются как кириллические.
Госномер должен быть уникальным среди ТС в базе.
