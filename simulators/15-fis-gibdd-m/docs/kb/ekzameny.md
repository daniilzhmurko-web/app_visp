# Экзамены на право управления
tags: экзамен, теория, площадка, город, пересдача

Этапы строго по порядку: теория → площадка → город. К следующему этапу допускают только после успешного предыдущего.
Повторная сдача после неудачи — не ранее чем через 7 дней. Кнопка «Записать» сохраняет результат; ВУ выдают только если все три этапа сданы.
Результат экзамена хранится в базе и проверяется при выдаче ВУ.
