# Токен доступа и отчёт
tags: токен, отчёт, проверка, json, выгрузка

Если преподаватель выдал токен — вставьте его на форме входа (или откройте ссылку с токеном): ФИО подтянется автоматически и не редактируется.
По завершении нажмите «Отчёт» → JSON и передайте файл на проверку. В отчёт входят токен, метки привязки, журнал действий, ошибки и контрольная сумма.
