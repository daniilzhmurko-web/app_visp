# Задания с межведомственной проверкой
tags: задание, запрос, решение, ответ, сценарий

Часть заданий выдаётся по разделу «Сервисы ГИБДД». В карточке задания описана ситуация (гражданин, ТС, документы).
Порядок: 1) отправьте запросы в нужные ведомства — по данным из задания (паспорт, VIN или госномер); 2) прочитайте ответы; 3) выберите решение и нажмите «Подтвердить решение». Решение доступно только после получения всех ответов.
Запрос с чужим предметом не засчитывается. Неверное решение — ошибка (минус баллы, 5 ошибок — провал задания). В режиме «Экзамен» подсказки и пояснения не показываются.
