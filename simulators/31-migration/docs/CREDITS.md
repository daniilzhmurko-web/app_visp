# Источники и лицензии
- **SOCOFing** — Sokoto Coventry Fingerprint Dataset (Shehu Y.I., Ruiz-Garcia A., Palade V., James A., 2018), лицензия CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Требуется указание авторства.
- Синтетические фото — по условиям выбранного генератора (genphoto): проверьте лицензию на использование в учебных материалах.
- Правила работы приложения «Амина» (эксперимент в Москве и МО с 01.09.2025: геолокация, 3 раб. дня до уведомления, ещё 3 — снятие с учёта по адресу ММЦ, реестр контролируемых лиц) — по открытым публикациям; смоделированы упрощённо для обучения. Сверьте с действующими нормативными актами.
