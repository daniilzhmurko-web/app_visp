# КСЕНОН-2 — учебный симулятор

Два варианта запуска (Chrome / Edge / Firefox):

| Файл | Когда использовать |
|---|---|
| `ksenon2_simulator_standalone.html` | **всё в одном файле** (~6 МБ): открывается где угодно, в том числе в предпросмотре и при отправке одним файлом |
| `ksenon2_simulator.html` + папки `data/`, `assets/` | основной вариант: лёгкий HTML (~170 КБ), данные правятся отдельными файлами |

Для второго варианта папки должны лежать рядом с HTML. Переносите папку целиком (или архив `ksenon2.zip`).
После правки файлов в `data/` или `assets/` пересоберите автономный вариант — он содержит копию данных и логотипов на момент сборки.

```
ksenon2/
├─ ksenon2_simulator.html
├─ ksenon2_simulator_standalone.html
├─ КСЕНОН-2_руководство.html   руководство пользователя (работает офлайн)
├─ assets/   Chart.js, шрифт иконок, dna_engine.js (движок ДНК-экосистемы), img/logo_1.webp, img/logo_2.webp
└─ data/     данные (см. data/README.md)
```

ДНК-экосистема встроена в симулятор: меню «ДНК-экосистема» (справочник локусов, генератор профилей, эталонные наборы,
параметры расчёта) и переключатель популяций. Движок — `assets/dna_engine.js`, данные — `data/ecosystem/`.
Российские частоты можно добавить прямо в симуляторе («Параметры расчёта» → «Импорт популяции из CSV»).

Заменить логотипы: положите свои файлы с теми же именами в `assets/img/` (прозрачный фон, WebP/PNG-содержимое,
логотип 1 — около 800 px по ширине, логотип 2 — около 600 px).

Сборка автономного файла: см. `tools/build_standalone.py` (`python3 tools/build_standalone.py <папка ksenon2> <выходной.html>`).
