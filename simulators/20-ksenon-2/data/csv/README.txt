КСЕНОН-2 · справочные CSV-таблицы ДНК-экосистемы
=================================================
Симулятор эти файлы не читает: они нужны для просмотра в Excel, анализа и обмена.
Все данные учебные; частоты — из открытых публикаций (источники указаны в populations_summary.csv).

Файл                                  Содержимое
loci_reference.csv                    32 маркера: хромосома, позиция, мотив повтора, диапазон аллелей, тип, наборы
kit_definitions.csv                   состав наборов в длинном виде: набор, позиция, локус
kit_membership.csv                    матрица «локус × набор» (1 = входит)
populations_summary.csv               20 популяций: набор данных, группа, N, число локусов, p_min = 5/2N, источник
frequencies_nist_1036.csv             частоты NIST 1036 (США): исходные и нормализованные
frequencies_fbi_2015.csv              частоты FBI 2015 (США, 12 групп)
frequencies_uk_dna17.csv              частоты UK DNA-17 (Великобритания, 4 группы)
populations_import/<набор>__<группа>.csv   по одному файлу на группу в формате импорта симулятора
benchmark_full/partial/mixtures.csv   эталонные пары (синтетические) для проверки сравнения
russian_15_template.csv               (в папке templates) шаблон для российских частот, частоты пустые

Excel (русская локаль): откройте через «Данные → Из текста/CSV» и задайте для столбца allele тип «Текст»,
иначе аллели вида 9.3 превратятся в даты. Импорт в симулятор понимает и «;», и десятичную запятую,
и аллели вида 9,3, поэтому файл, пересохранённый из Excel, импортируется корректно.
