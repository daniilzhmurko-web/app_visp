## Где смотреть
Меню **«Учёты и базы»**: вкладка на каждый учёт, поиск по всем полям, постраничный просмотр (по 25),
кнопка «В ДНК-анализ» у ДНК-записей. Тяжёлые списки в других разделах ограничены (реестр — 100, дела — 40,
пользователи — 40, аудит — 200); поиск в «Реестре улик» идёт по всей базе.

## Сценарные записи
Первые записи в `db/*` (7 профилей, 5 дел, 5 запросов, 5 пользователей, 13 событий аудита, все узлы и копии)
сценарные: на них завязаны задания. Не меняйте и не удаляйте их; новые добавляйте после.

## Как добавить свои данные
1. `registers/custom/records.js` → массив `profiles` (образец — в комментарии файла). Профили добавляются в основную
   базу ДНК автоматически; дубли `id` и записи без `id`/`loci` пропускаются.
2. Для других учётов — записи в `records` нужного `registers/<учёт>/records.js` (поля — см. `view.cols` в `catalog.js`).
3. Формат UTF-8, `id` уникальны. Обновите страницу (F5).

## Важно
- Только вымышленные данные: не помещайте реальные ДНК-профили, персональные данные и сведения служебного пользования.
- Реальные интерфейсы и форматы обмена систем МВД не публичны и здесь не воспроизводятся.
- Если файлы не найдены, симулятор покажет сообщение (без ошибок в коде) и подскажет открыть автономный файл.

## Расследования по учётам (задания M38–M42)
В «Учётах и базах»: клик по строке — карточка записи со связями (ссылки на другие записи, дела, группы гильз); кнопка «Все учёты» — сквозной поиск по 8 учётам; «Поиск по ДНК» — поиск кандидатов в ФБДГИ и региональных банках (полное совпадение / родство); «В папку расследования» и проверка выводов — внизу страницы. Условия заданий и проверки описаны в `core/missions.js` (поле `inv`).
