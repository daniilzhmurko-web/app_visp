# АДИС «Папилон» — учебный симулятор (СЭКО, МВД России)

Многофайловый сайт. Точка входа — `index.html`.

## Запуск
- **Локально, без сервера (основной способ):** откройте `index.html` двойным кликом в Chrome / Edge / Firefox. Установка и веб-сервер не нужны;
  справочная база встроена в `data/data.js`, прогресс хранится в браузере (localStorage).
- **Необязательно — сервер с базой SQLite:** `start.bat` (Windows) или `./start.sh`, затем http://localhost:8080/ (нужен только Python 3.8+).
  Сессии и журналы курсантов сохраняются в `db/papilon.sqlite`, преподаватель видит результаты на `/results.html`
  (доступ можно закрыть: `PAPILON_ADMIN_KEY=секрет`, адрес `/results.html?key=секрет`).

## Структура
| Путь | Назначение |
|---|---|
| `index.html` | разметка приложения |
| `css/style.css`, `css/icons.css` | стили; строгие линейные иконки |
| `js/boot.js` | загрузка данных (API или JSON) и подключение модулей |
| `js/icons.js` | набор SVG-иконок, замена эмодзи, `stripEmoji()` |
| `js/api.js` | синхронизация сессии курсанта с сервером |
| `js/app/NN-*.js` | модули приложения (данные, движок АДИС, состояние, журнал, авторизация, экраны, миссии, отчёт) |
| `data/data.js` | встроенная копия базы для запуска без сервера (пересборка: `python3 tools/build_data_js.py`) |
| `data/fp_minutiae.json` | реальные минуции, извлечённые из изображений (`python3 tools/extract_minutiae.py`; нужны numpy, scipy, opencv-python, scikit-image) |
| `data/*.json` | справочные базы: дактилокарты, следы, миссии, ответы наставника, маски контуров отпечатков |
| `assets/fingerprints/` | 60 изображений отпечатков (D061–D066 используют зеркальные копии) |
| `db/schema.sql`, `tools/build_db.py` | схема SQLite и сборка базы из `data/` (база создаётся автоматически при первом запуске) |
| `server.py` | статика + API: `/api/ref`, `/api/session`, `/api/results`, `/api/health` |
| `results.html` | сводка результатов курсантов |

Изменили `data/*.json` — выполните `python3 tools/build_data_js.py` (для локального запуска) и `python3 tools/build_db.py` (для сервера).

## Регистрация следа из внутренней базы
На экране «Регистрация следа» кнопка «Из базы отпечатков» открывает каталог дактилокарт: выбранный отпечаток становится изображением нового следа, а его владелец — истинным кандидатом при поиске.

## Ограничения
- Токен курсанта проверяется только на клиенте (подпись не верифицируется) — для настоящего контроля нужна серверная проверка.
- Эталонные минуции извлекаются из изображений автоматически (скелетизация гребней, фильтрация шума) и не проверены экспертом: часть точек может не совпадать с разметкой специалиста.
