# Автотесты СОДЧ-М

Запуск: `npm i jsdom`, затем `node tests/run.js` из папки SODCH-M.

Проверяется: загрузка, число миссий и шагов, отсутствие ложного зачёта шагов и заданий экзамена на чистых данных,
детерминизм вариантов экзамена, реальное прохождение миссии 3, назначение наряда и блокировки (отпуск, занятый позывной),
сброс данных, зачёт реальных действий в экзамене, структура JSON-отчёта, отсутствие JS-ошибок.

Не проверяется автоматически: шаги, зависящие от состояния предыдущего шага (список DEP в run.js), и прохождение
каждой миссии реальными действиями (покрыта миссия 3 и сценарий назначения наряда). Остальное проверять руками.
`STEPS.md` и `steps_table.json` — таблица шагов с проверками.
