# Симуляторы

Для каждого сервиса ИСОД есть папка `NN-слаг/` (например `25-ciadis/`). Кнопка «Воспользоваться сервисом» открывает
`simulators/NN-слаг/index.html`.

Два варианта содержимого папки:
1. **Один файл** `index.html` (всё внутри, состояние в localStorage) — см. `_template-single/`.
2. **index.html + подпапки** (`css/`, `js/`, `data/`, `img/`, ...), всё подключается относительными путями — см. `_template-multi/`.

Точка входа всегда `index.html`. Вернуться на портал: ссылка `../../index.html`.
Чтобы симуляторы не мешали друг другу в localStorage, используйте префикс ключей: `sim:<слаг>:...`.
Общие файлы можно держать в `../assets/` и подключать как `../../assets/...`.

После добавления/удаления симулятора запустите `python tools/scan_simulators.py` — реестр `data/sim-files.js` обновится.
